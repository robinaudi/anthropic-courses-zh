```python
import re
import anthropic

# Retrieve the API_KEY & MODEL_NAME variables from the IPython store
%store -r API_KEY
%store -r MODEL_NAME

client = anthropic.Anthropic(api_key=API_KEY)

# Has been rewritten to take in a messages list of arbitrary length
def get_completion(messages, system_prompt=""):
    message = client.messages.create(
        model=MODEL_NAME,
        max_tokens=2000,
        temperature=0.0,
        system=system_prompt,
        messages=messages
    )
    return message.content[0].text
```

## 課程內容

有句話說：「寫作就是改寫。」事實上，**Claude 在被要求重新審視時，往往能提升回應的準確度**！

讓 Claude「再想想」的方式有很多種。那些讓人覺得自然地請人類再次確認工作的方式，通常對 Claude 也同樣有效。（請參閱我們的[提示詞串接文件](https://docs.anthropic.com/claude/docs/chain-prompts)，了解更多使用提示詞串接的時機與方法範例。）

### 範例

在這個範例中，我們要求 Claude 列出十個單字……但其中一個或多個並不是真實存在的單字。

```python
# Initial prompt
first_user = "Name ten words that all end with the exact letters 'ab'."

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    }
]

# Store and print Claude's response
first_response = get_completion(messages)
print(first_response)
```

**要求 Claude 讓答案更準確**可以修正這個錯誤！

以下範例中，我們取出 Claude 上方不正確的回應，並在對話中加入另一輪，要求 Claude 修正先前的答案。

```python
second_user = "Please find replacements for all 'words' that are not real words."

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    
    },
    {
        "role": "assistant",
        "content": first_response
    
    },
    {
        "role": "user",
        "content": second_user
    
    }
]

# Print Claude's response
print("------------------------ Full messsages array with variable substutions ------------------------")
print(messages)
print("\n------------------------------------- Claude's response -------------------------------------")
print(get_completion(messages))
```

但 Claude 是不是因為我們叫它修改就修改了？如果一開始的答案就是正確的呢？Claude 會失去信心嗎？以下範例中，我們將一個正確的回應放在 `first_response` 的位置，再次要求它重新確認。

```python
first_user = "Name ten words that all end with the exact letters 'ab'."

first_response = """Here are 10 words that end with the letters 'ab':

1. Cab
2. Dab
3. Grab
4. Gab
5. Jab
6. Lab
7. Nab
8. Slab
9. Tab
10. Blab"""

second_user = "Please find replacements for all 'words' that are not real words."

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    
    },
    {
        "role": "assistant",
        "content": first_response
    
    },
    {
        "role": "user",
        "content": second_user
    
    }
]

# Print Claude's response
print("------------------------ Full messsages array with variable substutions ------------------------")
print(messages)
print("\n------------------------------------- Claude's response -------------------------------------")
print(get_completion(messages))
```

您可能會注意到，如果多次執行上方程式碼區塊，Claude 大多數時候會保持原有的單字不變，但偶爾仍會更動單字，即使它們全都是正確的。我們能如何緩解這個問題？根據第八章，我們可以給 Claude 一個退路！讓我們再試一次。

```python
first_user = "Name ten words that all end with the exact letters 'ab'."

first_response = """Here are 10 words that end with the letters 'ab':

1. Cab
2. Dab
3. Grab
4. Gab
5. Jab
6. Lab
7. Nab
8. Slab
9. Tab
10. Blab"""

second_user = "Please find replacements for all 'words' that are not real words. If all the words are real words, return the original list."

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    
    },
    {
        "role": "assistant",
        "content": first_response
    
    },
    {
        "role": "user",
        "content": second_user
    
    }
]

# Print Claude's response
print("------------------------ Full messsages array with variable substutions ------------------------")
print(messages)
print("\n------------------------------------- Claude's response -------------------------------------")
print(get_completion(messages))
```

多次執行上方程式碼，您會發現 Claude 現在更能堅持自己原本的答案了。

您也可以使用提示詞串接**要求 Claude 改善其回應**。以下範例中，我們先要求 Claude 寫一個故事，然後改善它所寫的故事。個人品味可能有所不同，但許多人可能會同意 Claude 的第二版更好。

首先，讓我們產生 Claude 的第一版故事。

```python
# Initial prompt
first_user = "Write a three-sentence short story about a girl who likes to run."

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    }
]

# Store and print Claude's response
first_response = get_completion(messages)
print(first_response)
```

現在讓 Claude 在第一稿的基礎上進行改進。

```python
second_user = "Make the story better."

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    
    },
    {
        "role": "assistant",
        "content": first_response
    
    },
    {
        "role": "user",
        "content": second_user
    
    }
]

# Print Claude's response
print("------------------------ Full messsages array with variable substutions ------------------------")
print(messages)
print("\n------------------------------------- Claude's response -------------------------------------")
print(get_completion(messages))
```

這種替換方式非常強大。我們一直使用替換佔位符來傳入清單、單字、Claude 先前的回應等內容。您也可以**使用替換來執行我們所謂的「函式呼叫」——要求 Claude 執行某個函式，然後將該函式的結果傳入後續提示詞，讓 Claude 基於結果進一步處理**。其運作方式與其他替換相同。更多詳情請見下一個附錄。

以下是另一個範例，將一次 Claude 呼叫的結果帶入另一個更長的呼叫中。讓我們從第一個提示詞開始（這次包含 Claude 回應的預填）。

```python
first_user = """Find all names from the below text:

"Hey, Jesse. It's me, Erin. I'm calling about the party that Joey is throwing tomorrow. Keisha said she would come and I think Mel will be there too."""

prefill = "<names>"

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    
    },
    {
        "role": "assistant",
        "content": prefill
    
    }
]

# Store and print Claude's response
first_response = get_completion(messages)
print("------------------------ Full messsages array with variable substutions ------------------------")
print(messages)
print("\n------------------------------------- Claude's response -------------------------------------")
print(first_response)
```

讓我們將這個姓名清單傳入另一個提示詞。

```python
second_user = "Alphabetize the list."

# API messages array
messages = [
    {
        "role": "user",
        "content": first_user
    
    },
    {
        "role": "assistant",
        "content": prefill + "\n" + first_response
    
    },
    {
        "role": "user",
        "content": second_user
    
    }
]

# Print Claude's response
print("------------------------ Full messsages array with variable substutions ------------------------")
print(messages)
print("\n------------------------------------- Claude's response -------------------------------------")
print(get_completion(messages))
```
