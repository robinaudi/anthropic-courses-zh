# 附錄 10.3：搜尋與資料擷取

您知道嗎？您可以使用 Claude **代您搜尋 Wikipedia**！Claude 能找到並擷取文章，接著您還可以讓 Claude 摘要與綜合這些文章、根據所找到的內容創作新文章，以及更多其他用途。而且不僅限於 Wikipedia！您也可以在自己的文件上進行搜尋，無論是以純文字形式儲存，還是嵌入在向量資料庫中。

請參閱我們的 [RAG cookbook 範例](https://github.com/anthropics/anthropic-cookbook/blob/main/third_party/Wikipedia/wikipedia-search-cookbook.ipynb)，學習如何透過從向量資料庫、Wikipedia、網際網路等來源擷取的資料，補充 Claude 的知識並提升 Claude 回應的準確性與相關性。您也可以在那裡學習如何使用特定的[嵌入（embeddings）](https://docs.anthropic.com/claude/docs/embeddings)和向量資料庫工具。

若您有興趣學習使用 Claude 的進階 RAG 架構，請查看我們的 [Claude 3 RAG 架構技術簡報投影片](https://docs.google.com/presentation/d/1zxkSI7lLUBrZycA-_znwqu8DDyVhHLkQGScvzaZrUns/edit#slide=id.g2c736259dac_63_782)。
