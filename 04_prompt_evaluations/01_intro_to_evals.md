# 評估入門 101

本課程（以及後續八堂課）聚焦於 LLM 使用情境評估的撰寫方法，這是開發 AI 應用程式的核心環節。

在人工智慧快速演進的今天，大型語言模型已成為各行各業強而有力的工具。然而，要充分發揮這些模型的潛能，光靠實作是不夠的——還需要仔細的評估與優化。這正是提示詞評估（簡稱「evals」）的用武之地。

以下是我們內部解決方案架構師團隊對於評估重要性的真實說法：

>團隊無法量化模型效能，是 LLM 生產應用的最大瓶頸，也讓提示工程從科學變成了藝術

>雖然評估很費時，但預先做好評估，長遠來看能節省開發時間，也能讓更好的產品更早問世

開發者不寫評估的原因主要有兩個：
1. 許多人對評估的概念完全陌生
2. 不清楚如何實際實作評估

本課程旨在解答這兩個問題：評估是什麼，以及如何撰寫評估。

本入門課程先解決第一個問題，介紹評估的概念，並概述各種評估方法。

## 基準測試（Benchmarks）
在深入探討客戶評估之前，先來看看大多數人最熟悉的一種評估形式：模型基準測試。

模型基準測試就像 AI 世界的標準化考試。就像 SAT 分數能讓大學對學生的學術能力有初步了解，模型基準測試讓我們對 AI 模型在各類任務上的表現有一個整體認識。

開發大型語言模型的公司會執行這些基準測試，以展示模型的能力。你可能見過 ARC、MMLU、TruthfulQA 等名稱各異的測試分數。這些基準測試涵蓋從基礎閱讀理解到跨領域進階推理的各種項目，有助於比較不同模型並追蹤 AI 整體能力的進展。你可能見過展示基準測試分數的模型卡：

![benchmarks.png](images/benchmarks.png)



雖然這些基準測試在彰顯模型能力上很有用，但它們並非全貌。這就像知道一個人的 IQ 分數——可能（也可能不）告訴你他的整體智力，但不會告訴你他是否適合你的特定工作。

## 客戶評估

想像你剛買了一把閃亮的瑞士刀。它有幾十種工具，但你主要想用它在露營時開罐頭。當然，它能銼指甲或開酒瓶也很好，但它開罐頭的效果到底怎麼樣？這就是提示詞評估對大型語言模型的意義。

LLM 就像文字世界的超強瑞士刀。它們能用語言做各種驚人的事，從寫詩到編寫程式碼都難不倒。但當你把 LLM 用於特定任務——例如回覆客服郵件或生成產品描述——你需要知道它在這項特定工作上的表現。

這就是提示詞評估（簡稱「evals」）登場的時刻。提示詞評估（也稱為客戶評估）是一種系統性測試，旨在衡量 LLM 在你的特定使用情境上的表現。它是 LLM 通用能力與你的業務應用獨特需求之間的重要橋梁。透過完善的評估，你可以確保模型與提示詞的組合不僅符合通用基準，也能在你需要的特定任務上表現出色。

評估的主要好處包括：

* 迭代式提示詞改進——v2 版本的提示詞在特定任務上是否比 v1 更好？
* 部署前後與提示詞變更後的品質保障——最新的提示詞更新是否造成效能退步？
* 客觀的模型比較——切換到 Anthropic 最新模型後，能否維持或超越目前的評估表現？
* 潛在的成本節省——切換到 Anthropic 最便宜、最快的模型後，能否維持目前的評估表現？

在撰寫和優化提示詞時，我們遵循一個以評估為核心的迭代流程：

![process.png](images/process.png)



---

* 首先建立測試案例，稍後會詳細介紹。
* 接著為特定使用情境撰寫初版提示詞草稿。
* 然後用測試案例集測試提示詞，衡量模型在指定任務上的表現，取得基準分數。
* 有了基準分數後，就可以修改提示詞並重複這個流程。

評估的核心在於指定指標，量化提示詞與模型組合的品質。沒有量化的衡量標準，我們怎麼知道修改提示詞是否帶來了改善？

## 評估的組成要素

一個設計良好的提示詞評估包含四個主要元素：

* **範例輸入（Example Input）：** 給予模型的指令或問題。設計的提示詞必須能準確代表應用程式在真實世界中遇到的各種輸入。
* **黃金答案（Golden Answer）：** 正確或理想的回應，作為評估模型輸出的基準。製作高品質的黃金答案通常需要主題專家的投入，以確保準確性和相關性。
* **模型輸出（Model Output）：** LLM 根據輸入提示詞實際產生的回應，也就是你要對照黃金答案進行評估的內容。
* **分數（Score）：** 代表模型在特定輸入上表現的量化或質化數值。評分方式因任務性質和所選評分方法而異。

![eval_diagram.png](images/eval_diagram.png)

**我們通常建議至少 100 組測試案例與黃金答案配對，以取得最佳結果。但為了降低學習本課程的 API 費用，我們大多數的評估將使用遠少於此的配對數量。**

### 評估資料集範例

假設我們想用 LLM 對客戶投訴進行分類，一個（非常小的）評估資料集可能長這樣：

```py
eval_data = [
    {
        "complaint": "The app crashes every time I try to upload a photo",
        "golden_answer": ["Software Bug"]
    },
    {
        "complaint": "My printer isn't recognized by my computer",
        "golden_answer": ["Hardware Malfunction"]
    },
    {
        "complaint": "I can't figure out how to change my password",
        "golden_answer": ["User Error"]
    }
]
```
每個輸入投訴都對應一個黃金答案分類。我們將在後續課程中擴展這個範例，學習如何執行並評分這個評估。

## 評分方法

選擇正確的評分方法對評估的有效性至關重要。每種方法各有其優勢，適合不同類型的任務。

---

### 人工評分

對於需要細緻理解或主觀判斷的任務，人工評分仍是黃金標準。這種方法讓人員——通常是主題專家——審查模型輸出、評估品質，並為每個輸出打分。

人工評分在評估語調、創意、複雜推理，或專家級領域的事實性等面向特別出色。當面對開放式任務，或答案的正確性取決於微妙情境因素時，它尤其有價值。缺點是耗時且費用昂貴，尤其是大規模評估時。不同評分者之間也可能存在不一致的問題。

人工評分的形式包括：

* **專家審查（Expert Review）：** 領域專家評估回應的準確性和深度。例如，針對討論房貸選項的銀行聊天機器人，律師可能手動審查回應，確保符合公平貸款法規並準確呈現條款。皮膚科醫生可能評估模型的皮膚癌篩查建議，檢查識別是否正確、緊急程度是否適當，以及是否符合最新研究。
* **使用者體驗小組（User Experience Panel）：** 由一群人評估輸出的清晰度、實用性、參與度及其他人性化面向。

### 程式碼評分

程式碼評分使用程式化方法來評估模型輸出。這種方法適合具有明確客觀標準的任務。例如，如果你使用 LLM 從文字中提取特定資料點，可以用程式碼檢查提取的資訊是否符合預期值。

程式碼評分的主要優點是速度快且可擴展性強。一旦設定完成，就能快速且一致地處理數千個評估。但它處理細緻或主觀回應的能力有限。常見的程式碼評分技術包括精確字串比對、關鍵字存在性檢查，以及使用正則表達式的模式比對。

程式碼評分的形式包括：
* **精確字串比對評分（Exact String Match Grading）** ——這是最嚴格的形式，模型輸出必須與黃金答案逐字元完全相同。就像只有一個正確答案的選擇題。例如地理測驗中，「法國的首都是哪裡？」唯一接受的答案是「巴黎」。
* **關鍵字存在性（Keyword Presence）** ——這種方法檢查模型輸出中是否包含特定關鍵字或片語，不論其順序或上下文。例如，產品支援聊天機器人中，「如何重置我的 SmartHome 恆溫器？」可能要求答案中必須包含「按住」、「按鈕」、「5 秒」和「閃爍指示燈」等關鍵字。
* **正則表達式（Regex）：** 可以定義正則表達式來檢查複雜的文字模式。評估信用卡資格的銀行聊天機器人可能需要符合模式「Your credit score of \d{3} (qualifies|does not qualify) you for our \w+ Card」，以確保同時提供分數和結果。
* 以及更多其他形式！

### LLM 評分
LLM 評分是程式碼評分和人工評分之間的折衷方案。這種方法使用另一個 LLM（有時是同一個）來評估輸出。透過精心設計的評分提示詞，可以利用 LLM 的語言理解能力評估各種標準。

這種方法能處理比程式碼評分更複雜、更主觀的評估，同時比人工評分更快速、更具可擴展性。但它需要熟練的提示工程才能確保可靠的結果，且評分 LLM 有可能引入自身偏見。

模型評分的形式包括：
* **摘要品質（Summarization Quality）** ——這份摘要有多精簡、多準確？
* **語調評估（Tone Assessment）** ——這個回應是否符合我們的品牌規範或語氣準則？
* **任何其他品質指標！** ——我們可以定義自訂評分標準，讓大型語言模型依照我們能想到的任何指標對輸出進行評分：輸出有多道歉？輸出是否提到競爭對手？

## 結語 

建立完善的提示詞評估是開發有效 LLM 應用的關鍵步驟。透過系統性地測試和優化提示詞，你可以確保應用程式持續提供符合特定需求的高品質結果。請記住，投入時間建立良好評估，將在提升效能、簡化優化流程，以及增強對 LLM 解決方案信心方面得到豐厚回報。
