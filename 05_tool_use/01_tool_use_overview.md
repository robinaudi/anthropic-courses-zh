# 工具使用基礎

## 學習目標

## 什麼是工具使用？
工具使用（tool use），又稱函數呼叫（function calling），是指透過定義並呼叫外部工具或函數來擴展 Claude 能力的機制。我們可以賦予 Claude 一組預先定義的工具，讓它在任何時間點呼叫。工具讓我們能夠撰寫可執行特定任務或運算的程式碼，完成 Claude 原本無法做到的事情。簡而言之：工具使用是強化 Claude 功能性的一種方式。

## 為什麼這很重要？
工具使用是一個顛覆性的功能，能解鎖 Claude 的真正潛能，開啟無限可能。它是一個關鍵元件，可以大幅提升你的應用程式的價值與影響力。

* **擴展 Claude 的能力**
  * 工具使用讓你能夠將 Claude 的能力延伸至其內建功能之外。透過定義並呼叫外部工具，你可以讓 Claude 執行原本無法完成的任務。這意味著你可以打造功能更強大、更靈活的應用程式，滿足更廣泛的使用者需求。
* **整合既有系統**
  * 工具使用能讓 Claude 與你現有的系統、資料庫或 API 無縫整合。你可以定義與後端服務互動、從資料庫擷取資料、或觸發應用程式動作的工具。這種整合讓你在利用既有基礎架構與資料的同時，充分發揮 Claude 的能力。
* **自動化複雜任務**
  * 透過工具使用，你可以自動化涉及多個步驟或需要專業運算的複雜任務與工作流程。透過將這些任務封裝成工具，你可以簡化流程、減少人工操作、提升效率。Claude 能夠根據使用者輸入或預先設定的條件，在適當時機呼叫正確的工具。
* **提升使用者體驗**
  * 工具使用能顯著提升你的應用程式的使用者體驗。透過讓 Claude 存取相關工具，你可以讓它針對使用者查詢提供更精確、更符合情境且更個人化的回應。使用者可以用自然語言與你的應用程式互動，而 Claude 可以利用工具提供豐富資訊或代表使用者執行所需動作。
* **擴展與客製化**
  * 透過工具使用，你可以擴展並客製化你的應用程式以滿足使用者不斷演進的需求。隨著使用者群體成長或需求改變，你可以輕鬆新增工具或修改現有工具來擴充 Claude 的能力。這種靈活性讓你能夠快速適應與迭代，確保你的應用程式持續保持競爭力。

## 應用場景範例

以下是我們在使用工具使用的客戶中觀察到的幾個常見主題：

* **擷取資訊**
  * 工具可用於從外部來源（例如資料庫、API 或網路服務）取得資料。舉例來說，工具可以根據使用者輸入擷取天氣資訊、股票價格或新聞文章。
* **執行計算**
  * 工具可以執行 Claude 內建能力難以處理的複雜計算或數學運算，例如財務計算、科學運算或統計分析。
* **資料處理**
  * 工具可用於以各種格式處理、轉換或操作資料，例如資料格式化、資料擷取或資料轉換等任務。
* **與外部系統互動**
  * 工具可以協助與外部系統或服務互動，例如傳送電子郵件、觸發通知或控制 IoT 裝置。
* **生成內容**
  * 工具可以根據使用者輸入或預先定義的範本，協助生成特定類型的內容，例如圖像、圖表或格式化文件。

更具體的可能應用場景包括：

* **企業資料整合**：將 Claude 與 CRM、ERP 和 ITSM 等企業系統整合，以擷取客戶資料、自動化工作流程並提供個人化支援。
* **財務分析與報告**：使用 Claude 與工具分析財務資料、生成投資報告、評估風險並確保法規遵循。
* **醫療診斷與治療計畫**：將 Claude 與電子病歷（EHR）和醫學知識庫整合，協助醫療專業人員做出明智決策並制定個人化治療方案。
* **教育輔導與內容創作**：結合 Claude 與教育資源和工具，提供個人化輔導、生成學習材料，並適應個別學習風格。
* **法律文件分析與審閱**：使用 Claude 與工具分析法律文件、擷取關鍵資訊、識別潛在問題並生成摘要，以簡化法律流程。
* **客戶支援自動化**：將 Claude 與知識庫和支援票務系統整合，提供自動化客戶支援、排除問題並改善回應時間。
* **業務與行銷自動化**：結合 Claude 與工具分析客戶資料、生成個人化行銷內容、評估潛在客戶並優化業務流程。
* **軟體開發輔助**：將 Claude 與 IDE、版本控制系統和專案管理工具整合，協助開發人員撰寫程式碼、識別錯誤並管理軟體專案。
* **研究與創新**：結合 Claude 與工具進行市場研究、分析專利資料、產生新穎想法，並推動各產業的創新。
* **內容創作與優化**：使用 Claude 與工具為各種平台（包括網站、社群媒體和行銷活動）生成、優化並個人化內容。

## 工具使用的運作方式

讓我們將注意力轉向工具使用實際上是如何運作的。最重要的一點是：Claude 本身並不會*執行*任何程式碼。我們告訴 Claude 一組它可以要求我們呼叫的工具，然後由我們來實際執行底層的工具程式碼，並將結果回傳給 Claude。

請注意，Claude 沒有任何內建的伺服器端工具可存取。所有工具都必須由你（使用者）在每個 API 請求中明確提供。這意味著你必須定義可用工具（包含清楚的描述和輸入綱要），並在 Claude 要求時實作並執行工具邏輯（例如執行特定函數或查詢 API）。這讓你對 Claude 可使用的工具擁有完全的控制權與彈性。

![db_tool-2.png](images/db_tool-2.png)

具體而言，使用工具搭配 Claude 涉及以下步驟：

1. **提供 Claude 工具與使用者提示：**（API 請求）
    * 定義你希望 Claude 能存取的工具集合，包含其名稱、描述和輸入綱要。
    * 提供一個可能需要使用一個或多個工具才能回答的使用者提示，例如「我用 500 美元可以買多少股通用汽車的股票？」

2. **Claude 使用工具：**（API 回應）
    * Claude 評估使用者提示，判斷是否有任何可用工具能協助處理使用者的查詢或任務。若有，它也會決定要使用哪個（些）工具以及使用什麼輸入。
    * Claude 輸出格式正確的工具使用請求。
    * API 回應的 `stop_reason` 將為 `tool_use`，表示 Claude 希望使用外部工具。

3. **擷取工具輸入、執行程式碼並回傳結果：**（API 請求）
    * 在客戶端，你應從 Claude 的工具使用請求中擷取工具名稱和輸入。
    * 在客戶端執行實際的工具程式碼。
    * 透過繼續對話（包含 `tool_result` 內容區塊的新使用者訊息）將結果回傳給 Claude。

4. **Claude 利用工具結果制定回應：**（API 回應）
    * 收到工具結果後，Claude 將利用這些資訊對原始使用者提示制定最終回應。

步驟（3）和（4）是可選的——對於某些工作流程，Claude 使用工具的結果就是你所需的全部資訊，不一定需要將工具結果回傳給 Claude。後續章節會有更多說明。

### 假設性工具使用情境

為了更好地理解工具使用的流程，讓我們設想一個場景：我們正在建置一個聊天應用程式，讓使用者可以與 Claude 討論股票市場並獲取即時股價。

當然，Claude 不知道任何時間點的股市狀況和價格，因此我們需要提供 Claude 一個 `get_stock_price` 工具，用於擷取特定公司的即時股價。

### 流程詳細說明

以下是工具使用步驟的詳細說明

#### 步驟 0：撰寫工具功能

在告訴 Claude 某個工具的存在之前，我們需要先撰寫該工具的功能。以 `get_stock_price` 工具為例，我們可能會撰寫一個函數，接受公司名稱或股票代碼作為引數，然後向股市 API 發送請求以取得即時股票資料。大概像這樣：

```python
def get_stock_price(company):
    #Send a request to a stock market API to lookup current stock price for a given company

    #Returns a dictionary containing current stock price information for the specified company
```

如果這個函數已完整實作，當我們呼叫 `get_stock_price("General Motors")` 時，可能會得到如下的回傳值：

```python
{
  "symbol": "GM", 
  "price": 43.09
}
```

#### 步驟 1：提供 Claude 工具與使用者提示（API 請求）
接下來，我們需要定義 `get_stock_price` 工具的名稱、描述和輸入綱要。我們稍後會花更多時間介紹工具定義，但以下是一個假設性的 `get_stock_price` 工具定義範例：

```python
tool_definition = {
    "name": "get_stock_price",
    "description": "Retrieves the current stock price for a given company",
    "input_schema": {
        "type": "object",
        "properties": {
            "company": {
                "type": "string",
                "description": "The company name to fetch stock data for"
            }
        },
        "required": ["company"]
    }
}
```

接下來，我們告訴 Claude 這個工具的存在，並以可能需要用到此工具的提示發出請求：

```python
response = client.messages.create(
    model="claude-3-opus-20240229",
    messages=[{"role": "user", "content": "How many shares of General Motors can I buy with $500?"}],
    max_tokens=500,
    tools=[tool_definition]
)
```

#### 步驟 2：Claude 使用工具（API 回應）

Claude 收到 API 請求並評估使用者提示。它判斷 `get_stock_price` 工具有助於回答關於購買通用汽車股票的問題。

Claude 回應一個格式正確的工具使用請求。我們稍後會更深入探討這部分，但以下是 Claude 表示「想要」使用我們工具的範例回應：

```python
{
  "stop_reason": "tool_use",
  "tool_use": {
    "name": "get_stock_price",
    "input": {
      "company": "General Motors"
    }
  }
}
```

#### 步驟 3：擷取工具輸入、執行程式碼並回傳結果（API 請求）

在客戶端，我們從 Claude 的工具使用請求中擷取工具名稱（`get_stock_price`）和輸入的公司名稱（`General Motors`）。

我們執行實際的 `get_stock_price` 函數，使用從 Claude 工具請求中擷取的輸入，透過 API 取得即時股市資料。函數可能回傳如下資料：

```python
{
  "symbol": "GM", 
  "price": 43.09
}
```

然後我們告知 Claude 工具的執行結果。我們透過繼續對話（包含 `tool_result` 內容區塊的新使用者訊息）將股價工具結果回傳給 Claude（稍後會詳細說明）。

#### 步驟 4：Claude 利用工具結果制定回應（API 回應）

Claude 收到股價工具結果，並將即時股市資訊融入對原始使用者提示的最終回應，最終回應如下：

>根據目前每股 43.09 美元的價格，您用 500 美元大約可以買入 11 股通用汽車的股票。
